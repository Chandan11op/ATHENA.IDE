# ATHENA.IDE v0.2.0 (Early Development Release — Windows x64)

**Version:** `0.2.0`  
**Tag:** `v0.2.0`  
**Release Date:** 2026-11-28  
**Platform:** Windows 10 / 11 (64-bit, `x64`)

## Overview

`v0.2.0` is the first Windows desktop release of **ATHENA.IDE**, an offline-first, AI-assisted desktop IDE built on Electron 34, React 19, TypeScript, and Vite. After installing ATHENA.IDE, local Ollama, and a compatible coding model, core editing, file management, terminal, local preview, local Git, and AI workflows operate locally on your machine.

> **Early Development Notice:** This is an early development release (`0.2.0`) targeting Windows 10/11 x64. Installers are currently **unsigned**; Windows SmartScreen may display an "Unknown publisher" prompt until code signing is configured.

---

## Implemented Capabilities

- **VS Code-Inspired Workbench:** Dark+ default theme (with Light+ alternative), Activity Bar, resizable Explorer / Bottom Panel, Command Palette (`Ctrl+Shift+P`), and native menu bar.
- **Offline-Bundled Monaco Editor:** Multi-tab code editing, dirty indicators, `Ctrl+S` Save / `Ctrl+Shift+S` Save As, Word Wrap, diagnostics in Problems, and side-by-side DiffEditor.
- **Sandboxed Workspace Explorer & Search:** Workspace-contained file/folder CRUD, rename, confirmation-gated delete, path traversal guards, and `.env*` / private key exclusions.
- **Integrated Terminal & Local Preview:** Multi-session `@xterm/xterm` shell tabs and a `127.0.0.1` local HTML static preview server + consent-gated `npm` script runner.
- **`athena.data` Storage & Setup Wizard:** Structured `%APPDATA%/Athena.IDE/athena.data/` persistence, hardware check, Ollama discovery/startup, model download progress, inference verification, and 9-state Offline Readiness Diagnostics.
- **Local Git & Optional GitHub:** Local Git status, staging, commits, diffs, branches, and optional `safeStorage`-encrypted GitHub PAT integration.
- **Modular Local Extensions:** Local extension manifest management in `athena.data/extensions/` (arbitrary VS Code `.vsix` extensions are not supported).

## Installation & Local AI Setup

1. **Install ATHENA.IDE:** Run `Athena.IDE-0.2.0-win-x64-setup.exe` (or run `Athena.IDE-0.2.0-win-x64-portable.exe` directly without installation).
2. **System Requirements:**
   - Windows 10 or Windows 11 (64-bit)
   - 8 GB RAM minimum (16 GB recommended for 7B+ local coding models)
   - Node.js LTS and Git (for Node/Vite projects and local Source Control)
3. **Ollama & Model Requirements (Not Bundled):**
   - AI models and the Ollama runtime are **not** bundled inside the desktop installer.
   - Launch ATHENA.IDE and follow the built-in **Offline AI Setup Wizard** (supports guided `winget` installation or download from `https://ollama.com/download`), then pull a lightweight coding model such as `qwen2.5-coder:1.5b` (~1.0 GB) and run the in-app inference verification step.

## Known Limitations & Security Notes

- **Unsigned Executables:** Binaries do not yet carry an Authenticode certificate.
- **No Bundled AI Models:** Live AI chat and inline completions require a local Ollama daemon at `http://127.0.0.1:11434` and at least one pulled model.
- **Windows-Only Release Binaries:** macOS (`.dmg`) and Linux (`.AppImage` / `.deb`) builds are not included in `v0.2.0`.
- **Disconnected Testing Note:** Automated loopback HTTP tests pass; full physical network-disconnected verification should be validated per `docs/OFFLINE_TEST_PLAN.md`.
- **Troubleshooting:** If you only want to edit code without AI, click **Use Editor Without AI For Now** in the Setup Wizard.
